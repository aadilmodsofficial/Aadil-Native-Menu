# Aadil Native Menu

**A native Android Mod Menu template by Aadil Mods.**

Aadil Mod Menu is a floating mod menu template designed for Android game modding. It combines Java, JNI and C++ to provide a native menu interface with support for IL2CPP and other native Android games.

Developed and maintained by **Aadil Mods**.

## Introduction

Aadil Mod Menu provides a foundation for developing and integrating custom mod menus into Android games.

### Features

- Floating mod menu interface
- Java and JNI integration
- Native C++ functionality
- IL2CPP and native game support
- ARM64 architecture support
- Memory patching using KittyMemory
- Function hooking support
- Hexadecimal offset support
- String obfuscation
- Embedded DEX support through C++ headers
- Customizable menu elements and controls

## Compatibility

- Android 7 and above
- ARM64 (64-bit)
- IL2CPP and native Android games

Compatibility may vary depending on the game, Android version and native libraries.

## Getting Started

To get started with the project, check the **Docs** folder for setup instructions and implementation details.

You can customize the menu, add your own features and integrate it into supported Android games.

## Aadil Virtual

[Aadil Virtual](https://app.aadilmods.com) is another Android project developed by Aadil Mods.

It provides a virtual environment for running Android applications and games without requiring root access.

The mod menu template and Aadil Virtual are separate projects within the Aadil Mods ecosystem.
